# Teen Challenge Lietuva

Lithuanian nonprofit website for Teen Challenge Lietuva.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Wouter
- Lucide React

## Content

Most public copy is **placeholder** until verified against official Teen Challenge Lietuva information. Replace content in:

- `src/data/site.ts`
- `src/data/about.ts`
- `src/data/programs.ts`
- `src/data/stories.ts`
- `src/data/news.ts`
- `src/data/verse.ts`

Do not invent organizational facts in these files.
